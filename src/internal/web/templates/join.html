方式一：下載節點程式包（免編譯，推薦）

官方預編譯的純節點程式（不含錢包/交易所/社群等 DApp）。下載即用，不需 Go、不需編譯、不需整套系統原始碼。

curl -L -o /tmp/tacnode-package.zip http://2.28.201.174:8080/downloads/tacnode-package.zip
unzip -q /tmp/tacnode-package.zip -d /tmp/tacnode
sudo install -m 0755 /tmp/tacnode/tacweb /usr/local/bin/tacweb

啟動節點（把 <你的公網IP> 換成自己的公網 IP）：

sudo mkdir -p /var/tac/data
sudo /usr/local/bin/tacweb -data-dir /var/tac/data -web-port 8080 -rpc-port 8080 -serve-dapp=false -p2p -p2p-url http://<你的公網IP>:8080 -p2p-seed http://2.28.201.174:8080 -network mainnet

永久運行（systemd，開機自啟）：

sudo tee /etc/systemd/system/tacnode.service <<'EOF'
[Unit]
Description=TACm Node
After=network.target

[Service]
ExecStart=/usr/local/bin/tacweb -data-dir /var/tac/data -web-port 8080 -rpc-port 8080 -serve-dapp=false -p2p -p2p-url http://<你的公網IP>:8080 -p2p-seed http://2.28.201.174:8080 -network mainnet
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF
sudo systemctl daemon-reload && sudo systemctl enable --now tacnode

收款：首次啟動自動生成節點金鑰（/var/tac/data/node_key.json），節點地址＝你的收款錢包，出塊獎勵自動入帳。請立即備份：sudo cp /var/tac/data/node_key.json /root/node_key_backup.json

質押成為驗證人（去中心化共識）

創節點引導獎勵（限額 50 名）：新節點首次上線可領取 1,000 TACm 自動質押、直接成為驗證人——資金來自創世社群基金，每地址僅一次、限量 50 名（額滿即止）。領取方式：

curl -s -X POST http://<你的節點IP>:8080/api/node/bootstrap -H "Content-Type: application/json" -d '{}'

返回交易雜湊即領取成功；入塊後 1,000 TACm 入錢包並自動鎖入質押池。

質押 = 鎖幣取得驗證人資格，與主流 PoS（以太坊等）一致：節點把 TACm 鎖進鏈上質押池 → 進入驗證人集（每 60 秒由鏈上質押重放重建，全網一致）→ 輪值出塊、由在線節點均分 45% 節點獎勵。驗證人越多、出塊越分散，鏈越去中心化（最多 100 名同時輪值）。

門檻：質押 ≥ 1,000 TACm（質押高者優先入集）。質押幣鎖在鏈上質押池（鏈上可查），不可挪用。

第 1 步：確保節點錢包有幣

新節點初始餘額為 0，需先由其他持有者轉入（例如從創世節點錢包或交易所轉到你的節點地址）。節點地址＝節點金鑰對應地址，見節點面板／/var/tac/data/node_key.json。

第 2 步：發質押交易

在節點控制台（節點面板）點「質押成為驗證人」輸入金額，或直接呼叫 API：

curl -s -X POST http://<你的節點IP>:8080/api/node/stake -H "Content-Type: application/json" -d '{"amount":1000}'

成功後返回交易雜湊；交易入塊後最多 1 分鐘，節點自動進入驗證人集並開始輪值出塊。

第 3 步：領取獎勵

成為驗證人後：每塊 45% 節點獎勵由鏈上在線節點均分、直接入你的節點錢包（coinbase:node）。另可開啟算力成為礦工，按在線算力瓜分 40% 礦工獎勵（coinbase:miner）。兩者可同時開啟。

快照快速同步（重要）

節點啟動時加 -snapshot-url http://2.28.201.174:8080，會直接下載創世節點的最新狀態快照（創世+Tip+全帳戶餘額），秒級就緒，不再從創世逐塊重放（省 10 分鐘以上）。無磁碟的免費雲節點（Render 等）每次重啟都必須帶此參數，否則回到創世重放、長時間落後。

/usr/local/bin/tacweb -data-dir /var/tac/data -web-port 8080 -rpc-port 8080 -serve-dapp=false -p2p -p2p-url http://<你的公網IP>:8080 -p2p-seed http://2.28.201.174:8080 -network mainnet -snapshot-url http://2.28.201.174:8080

多驗證人注意事項

BFT 共識需 2/3 驗證人在線才持續出塊：2 個驗證人時任一離線鏈即暫停，建議驗證人達 3 個以上（容忍 1 個離線）。加入的驗證人越多，鏈的可用性與去中心化程度越高。
