啟動指令

以下指令一次一條，於節點伺服器執行：

sudo ./nodeweb -data-dir /var/tac/data -web-port 8081 -p2p -p2p-url http://<你的公網IP>:8081 -p2p-seed http://2.28.201.174:8080 -snapshot-url http://2.28.201.174:8080

🔒 P2P 通訊 v65 起預設加密（ECDH+AES-GCM），對端為舊版節點時自動降級明文；強制明文加 -p2p-plain。節點儀表 Peers 顯示 🔒加密／⚠明文。

開啟 http://<你的公網IP>:8081 即見節點品牌控制台。-snapshot-url 秒級同步全鏈快照，不需從創世重放。

下載節點程式（免編譯）

官方預編譯純節點程式，下載即用（不需 Go、不需編譯）：

curl -L -o /usr/local/bin/nodeweb http://2.28.201.174:8080/downloads/nodeweb && chmod +x /usr/local/bin/nodeweb
# 主鏈無法直連時改用 Render 備援下載中心（v72）：
# curl -L -o /usr/local/bin/nodeweb https://tacm-ai-cyprto.onrender.com/downloads/nodeweb && chmod +x /usr/local/bin/nodeweb
sudo mkdir -p /var/tac/data
sudo /usr/local/bin/nodeweb -data-dir /var/tac/data -web-port 8081 -p2p -p2p-url http://<你的公網IP>:8081 -p2p-seed http://2.28.201.174:8080 -snapshot-url http://2.28.201.174:8080

架設者依此下載、安裝並以 systemd 常駐；節點金鑰自動生成＝你的收款地址，請備份 node_key.json。

一行一鍵搭建

bash <(curl -fsSL http://2.28.201.174:8080/downloads/install-node.sh) # 主鏈不通時自動改用 Render 鏡像（v72）

已安裝節點一鍵升級到最新版（v74）：bash <(curl -fsSL http://2.28.201.174:8080/downloads/install-node.sh) update

自動偵測環境（systemd / nohup / render）、自動裝 Go、下載、編譯、啟動、偵測公網 IP。Render：推 GitHub → 新建 Web Service → Go runtime（render.yaml 自動配置）。⚠ 早期版本（需 Go 編譯），建議優先使用上方免編譯節點程式。

參與出塊（成為節點）

節點預設為跟隨模式（同步＋驗證＋BFT 投票，不主動出塊）。要參與出塊有二途徑：

  1. 質押成為節點：節點錢包質押 ≥ 1,000 TACm → 進入節點集（最多 21 名）→ 輪值出塊，均分 45% 節點獎勵。於節點控制台「質押」或 POST /api/node/stake {"amount":1000}。
  2. 在線時間權證（PoT）併入：節點未滿時，持續在線的 節點依時間權證併入出塊輪值，出塊即得 coinbase 分潤。

對鏈的影響：節點越多，出塊越分散、節點集越去中心化；BFT 需 2/3 節點在線才持續出塊，建議 ≥ 3 個節點（容忍 1 個離線）。質押與出塊紀錄全部上鏈、全網一致。
