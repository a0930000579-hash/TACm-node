Run Your Own Node

  1. Download the node package and unpack it on your server.
  2. Start with the same genesis anchor: --p2p-seed http://2.28.201.174:8080
  3. Watch this dashboard — your node will sync automatically and start validating blocks.
  4. Online nodes split the 45% node reward per block, withdrawable by the node key.

Update Node via Render (GitHub upload)

No SSH/terminal needed: upload the updated files (nodeweb etc.) to the GitHub repo root (tacm-node), overwriting the old ones; Render autoDeploy rebuilds automatically.

Render web upload: GitHub → repo root → Upload files → overwrite → Commit → Render detects the change and rebuilds.

One-Click Install (all platforms)

curl -L -o /tmp/tacnet-node.sh https://tacm-ai-cyprto.onrender.com/downloads/install-node.sh && bash /tmp/tacnet-node.sh

Auto-detects systemd / nohup / Render, installs Go, builds, starts and prints your console URL.

Source Code Permanent (GitHub)

cd tacm-go
git init -b main
git add -A
git commit -m "TAC Ai Smart Chain - v125"
git remote add origin https://github.com/<your-account>/TACm-Ai_Cyprto.git
git push -u origin main

After pushing, the node binary gets a permanent raw link — no more expiring short links:
curl -L -o /usr/local/bin/nodeweb https://raw.githubusercontent.com/<your-account>/TACm-Ai_Cyprto/main/tacm-go/nodeweb
