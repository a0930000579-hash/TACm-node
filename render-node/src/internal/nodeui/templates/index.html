Run Your Own Node

  1. Download the node package and unpack it on your server.
  2. Start with the same genesis anchor: --p2p-seed http://2.28.201.174:8080
  3. Watch this dashboard — your node will sync automatically and start validating blocks.
  4. Earn the 9% node reward per block, withdrawable by the node key.
