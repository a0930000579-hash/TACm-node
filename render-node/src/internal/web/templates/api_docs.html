Indexer API

公共只讀查詢面（Etherscan 風）——區塊、交易、地址與鏈統計，供開發者與工具整合。全部端點回傳 JSON。

端點 / Endpoints

Base URL：/api/v1
GET/api/v1/stats
鏈統計：高度、區塊數、交易數、帳戶數、Mempool 大小。
curl http://localhost:8080/api/v1/stats
GET/api/v1/blocks?limit=&offset=
區塊列表（高度降序）。limit 預設 20、上限 100。
curl "http://localhost:8080/api/v1/blocks?limit=10&offset=0"
GET/api/v1/block/{id}
單一區塊（高度或區塊哈希）＋區塊內交易。
curl http://localhost:8080/api/v1/block/1000
GET/api/v1/tx/{hash}
單一交易（64 位 hex 哈希）。
curl http://localhost:8080/api/v1/tx/<tx_hash>
GET/api/v1/txs?address=&limit=&offset=&dir=
地址交易歷史。dir 可選 in / out（僅收/僅發）。
curl "http://localhost:8080/api/v1/txs?address=tx01...&dir=out&limit=20"
GET/api/v1/address/{addr}
地址帳戶：餘額、Nonce、首末活躍時間與交易總數。
curl http://localhost:8080/api/v1/address/tx01...
GET/api/v1/delegations?limit=&offset=
質押委託分頁：全鏈委託紀錄（委託額降序，含委託人／驗證人／金額／時間）。
curl "http://localhost:8080/api/v1/delegations?limit=20"
GET/api/v1/delegations/{delegator}
委託人視角：全部委託明細＋累計委託獎勵（coinbase:deleg 鏈上入賬）。
curl http://localhost:8080/api/v1/delegations/tx01...
GET/api/v1/validators
驗證人排名：權重（自有＋委託）／委託總額／委託人數／狀態，權重降序。
curl http://localhost:8080/api/v1/validators

使用規範 / Usage

  • 全部端點為只讀，不消耗 Gas、不需簽名。
  • 分頁上限：limit ≤ 100；超大 offset 請配合時間篩選（後續版本）。
  • 錯誤回傳：404 not found（不存在）／400 invalid（參數/地址/哈希格式錯誤）／500（內部錯誤）。
  • 與 eth_* JSON-RPC 並存：RPC 面供錢包/合約，Indexer 面供瀏覽器與分析工具。
