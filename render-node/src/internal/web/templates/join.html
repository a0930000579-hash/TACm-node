方式 A：VPS 一鍵安裝（官方推薦）

任何 Ubuntu/Debian 伺服器貼上一行即可：自動下載 nodeweb、安裝至 /usr/local/bin、建立 systemd 服務並啟動，不需 Go、不需編譯。執行後自動以內建的多節點種子清單連線與抓快照，無單一控制點。

bash <(curl -fsSL https://tacm-ai-cyprto.onrender.com/downloads/install-node.sh)

已安裝節點一鍵更新：在同一段指令末尾加 update，即自動備份＋升級＋重啟。

bash <(curl -fsSL https://tacm-ai-cyprto.onrender.com/downloads/install-node.sh) update

腳本可從任一公開節點下載（把網址換成其他節點 URL 也行）；主鏈無法直連時自動改用 Render 備援下載中心。

方式 B：Render / DO 雲節點（免費雲平台）

從主網下載 render-node.zip（nodeweb＋Dockerfile＋render.yaml，免編譯）：

curl -L -o /tmp/render-node.zip http://2.28.201.174:8080/downloads/render-node.zip
unzip -q /tmp/render-node.zip -d /tmp/render-node

把 render-node/ 上傳 GitHub 公開 repo → Render 新建 Web Service 並選該 repo → 依 render.yaml 自動建置（autoDeploy）。啟動後自動從 seed 同步，免費層休眠後重啟會以快照秒級回補。

質押成為節點（去中心化共識）

創節點引導獎勵（限額 50 名）：新節點首次上線可領 1,000 TACm 自動質押、直接成為節點，資金來自創世社群基金，每地址僅一次、額滿即止。

curl -s -X POST http://<你的節點IP>:<埠>/api/node/bootstrap -H "Content-Type: application/json" -d '{}'

質押 = 鎖幣取得節點資格，與主流 PoS 一致：把 TACm 鎖進鏈上質押池 → 進入節點集（由鏈上質押重放重建，全網一致）→ 輪值出塊、在線節點均分 45% 節點獎勵。節點越多、出塊越分散，鏈越去中心化。

門檻：質押 ≥ 1,000 TACm（質押高者優先入集）。質押幣鎖在鏈上質押池，不可挪用。

第 1 步：確保節點錢包有幣

新節點初始餘額為 0，需先由其他持有者轉入。節點地址＝節點金鑰對應地址，見節點面板或 node_key.json。

第 2 步：發質押交易

curl -s -X POST http://<你的節點IP>:<埠>/api/node/stake -H "Content-Type: application/json" -d '{"amount":1000}'

交易入塊後最多 1 分鐘，節點自動進入節點集並開始輪值出塊。

第 3 步：領取獎勵

每塊 45% 節點獎勵由在線節點均分、直接入節點錢包；另可開啟礦機按算力瓜分 40% 礦工獎勵，兩者可同時進行。

多節點注意事項

BFT 需 2/3 節點在線才持續出塊：2 個節點時任一離線鏈即暫停，建議達 3 個以上（容忍 1 個離線）。
