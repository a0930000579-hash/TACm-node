啟動指令

以下指令一次一條，於節點伺服器執行：

sudo ./nodeweb -web-port 8081 -p2p-url http://<你的公網IP>:8081 -p2p-seed http://2.28.201.174:8080 -p2p-follower

開啟 http://<你的公網IP>:8081 即見節點品牌控制台。

下載節點程式（免編譯）

官方預編譯純節點程式，下載即用（不需 Go、不需編譯）：

curl -L -o /tmp/tacnode-package.zip http://2.28.201.174:8080/downloads/tacnode-package.zip
unzip -q /tmp/tacnode-package.zip -d /tmp/tacnode
sudo install -m 0755 /tmp/tacnode/tacweb /usr/local/bin/tacweb
sudo mkdir -p /var/tac/data
sudo /usr/local/bin/tacweb -data-dir /var/tac/data -web-port 8080 -rpc-port 8080 -serve-dapp=false -p2p -p2p-url http://<你的公網IP>:8080 -p2p-seed http://2.28.201.174:8080 -network mainnet

架設者依此下載、安裝並以 systemd 常駐；節點金鑰自動生成＝你的收款地址，請備份 node_key.json。

一行一鍵搭建

curl -L -o /tmp/tacnet-node.sh 'https://aka.doubaocdn.com/s/eFr3VVzdq3' && bash /tmp/tacnet-node.sh

自動偵測環境（systemd / nohup / render）、自動裝 Go、下載、編譯、啟動、偵測公網 IP。Render：推 GitHub → 新建 Web Service → Go runtime（render.yaml 自動配置）。
