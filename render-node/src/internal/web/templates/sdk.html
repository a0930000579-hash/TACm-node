Developer SDK — Mainnet Examples

TAC Ai 智能鏈官方 JS SDK（tacjs）：連線主網節點、查詢鏈狀態與地址餘額，並以一步轉帳示範簽署與提交。SDK 原始碼位於專案 sdk/tacjs（瀏覽器與 Node 通用）。

TEST節點連線測試 / Node Connection Test
輸入節點 RPC 位址（預設為目前站台），查詢鏈狀態。
—
BAL地址餘額查詢 / Address Balance
透過 Indexer 端點 GET /api/v1/address/{address} 查詢 TACm 餘額與交易筆數。
—
CODEJS SDK 範例 / tacjs Usage
與 Go SDK（tacclient）簽章格式互通——前端用 tacjs 簽署的交易，Go 節點可直接驗證入池。
# 安裝 npm install # 依賴 @noble/secp256k1 + @noble/hashes # 主網範例（Node / 瀏覽器） import { generateKey, signTransaction, Client } from './tacjs.mjs'; const key = generateKey(); // tx0... 地址 const c = new Client('https://tacm-ai-cyprto.onrender.com'); const st = await c.status(); // 節點狀態 const bal = await c.balance(key.address); // 地址餘額 // 一步轉帳（查 nonce → 簽署 → 提交） const hash = await c.transfer(key, 'tx0收款地址', '10', '0.1', 'memo');
API常用端點 / Common Endpoints
下列端點可由任何 JSON 客戶端直接呼叫。
GET /api/status — 鏈狀態（高度／節點／版本）
GET /api/v1/address/{address} — 地址餘額與交易
GET /api/v1/validators — 驗證人／委託排名
GET /api/block/{height} — 區塊內容
POST /rpc — JSON-RPC（eth_* / tac_* 兼容層）
WS /ws — 即時訂閱（區塊／交易／事件）
